# 품앗이룸 (가칭) — 메타버스 모의면접 웹 MVP 프로토타입

디프만 19기 5팀. 회의록 정리 · 기획서 · Figma IA(User Flow 최종)를 바탕으로 만든 실제 동작 웹앱이에요.

## 실행

```bash
cd ~/Documents/Claude/디프만-5팀/app
npm install
npm run dev        # http://localhost:5173
npm run build      # 배포용 빌드 (dist/)
```

- 비용: 유료 서비스·API 키를 쓰지 않아요. 음성 인식·음성 합성은 브라우저 내장 기능(Web Speech API)이에요.
- 데이터는 브라우저(localStorage / IndexedDB)에만 저장돼요. 계정·예약·기록·녹음 모두 이 기기 안에 있어요.
- 권장: 데스크톱 Chrome (음성 인식 지원). Safari/Firefox는 음성 인식이 없을 수 있어 글자 입력으로 대체돼요.

## 시험해 보는 순서

1. 랜딩 → 입장하기 → 회원가입 → 아바타 선택 → 자소서·이력(선택)
2. 로비에서 방향키(WASD)로 걸어가 예약 키오스크 (모바일은 조이스틱) → 면접방 예약
3. 우하단 **데모** 버튼 → 시간 이동(1시간 전 / 대기실 오픈 / 시작 20초 전) → 대기실 → 면접
4. 면접 종료 → 피드백 → 결과 → 면접 기록·질문카드 보관함
5. 면접관 역할도 예약해서 질문 카드로 면접을 진행해 볼 수 있어요
6. 같은 브라우저의 **탭 2개**에서 서로 다른 계정으로 같은 방을 예약하면 사람 대 사람으로 면접할 수 있어요

## 알려진 한계 · 다음 단계

- **다른 기기 간 실시간 연결은 아직 없어요.** 지금은 같은 브라우저의 탭끼리(BroadcastChannel)만 실시간으로 동기화돼요. 원격 사용자끼리 음성·상태를 주고받으려면 `lib/session.ts`의 전송 계층에 WebRTC(예: PeerJS 무료 공용 서버) 또는 서버를 붙이면 돼요.
- 질문 15+개는 **샘플**이에요. 현직자 인터뷰로 수집한 질문·의도·모범 답변 방향으로 `data/questions.ts`를 교체해야 해요.
- 상대 참가자(NPC)는 미리 정해진 질문·답변으로 움직여요. AI 생성은 MVP에서 제외했어요.
- 캐릭터는 제공받은 3종(남·여·콧수염) 이미지를 투명 배경 스프라이트로 잘라 썼어요. 앞·옆·뒤 시점만 있어서 앉은 모습은 상반신 크롭으로 표현해요.
- IA 안의 불일치: "30분 / 최소 20분", "피드백 1분 / 5분" → 각각 30분(1·2·3부 각 10분), 5분으로 구현했어요.
- 서비스 이름(품앗이룸)은 가칭이에요. `lib/core.ts`의 `APP_NAME`만 바꾸면 돼요.
